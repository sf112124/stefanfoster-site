# stefanfoster.com

Static site, no build step. Open `index.html` through any local server to preview.

- `index.html`, `style.css`: the page
- `app.js`: routing, project pages, player
- `field.js`: the home grid of work
- `wheel.js`: the curved index
- `thermal.js`, `melt.js`: WebGL heat field and melt transitions
- `sound.js`: foley
- `projects.js`: project titles, clients, blurbs, piece order
- `media.js` + `media/`: every image and film

Pushing to `main` deploys to Vercel automatically.
