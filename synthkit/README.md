# Synth-folio sounds

- `drums.wav`: three bars of the Amen break, four more breaks and a jungle kit, from the TidalCycles Dirt-Samples library (github.com/tidalcycles/Dirt-Samples).
- `fx.wav`, `bass.wav`: hoovers, rave stabs and vocals, jungle subs and 808s, from the same library.
- `films.wav`: chops from Stefan's own films.
- `samples.js` says where each sound sits in its file.
